Усі трекери міряють гроші. Цей міряє agent-active час — об'єднаний wall-clock,
коли Claude Code відповідав, з розбивкою по проєктах і без подвійного рахунку
паралельних сесій.

Один файл. Нуль залежностей. Без реєстрації. Нічого не виходить за межі твоєї машини.

![Тиждень агентної роботи як паперовий таймшит — великий agent-active час, погодинна сітка по днях, години по проєктах](assets/timesheet.jpg)

Різниця між `turn time` і `agent active` — це час перетину паралельних сесій.

## Установка

Встав це в Claude Code, і він поставить себе сам:

```
Встанови мені agent-hours: https://raw.githubusercontent.com/DrebotAI/agent-hours/v1.0.1/docs/install.md
```

Він перевірить версію Node, забере код, підніме твою історію і акуратно вмерджить
хуки в `settings.json`, не затерши ті, що вже є. На macOS, Linux і Windows однаково —
бо різницю між платформами розгрібає агент, а не ти.

<details>
<summary>Або руками</summary>

Потрібен Node 20.1+ (`node --version`).

```sh
git clone --branch v1.0.1 --depth 1 https://github.com/DrebotAI/agent-hours.git
cd agent-hours
node hours.mjs backfill
node hours.mjs report --days 30
node hours.mjs install    # надрукує блок для ~/.claude/settings.json
```

Команда `install` **друкує**, а не пише. Автоматичний мердж у чужий конфіг — це
найкоротший шлях зламати людині Claude Code, тому цей крок лишається за тобою.
Після вставки перезапусти Claude Code.

</details>

Цифру побачиш одразу. Claude Code з першого дня пише транскрипти з таймстампами в
`~/.claude/projects/`, і `backfill` їх читає — чекати тиждень не треба.

## Що записується

Чотири поля на live hook-подію, дописуються в `~/.agent-hours.jsonl`:

```json
{"at":"2026-08-03T10:14:02.117Z","source":"claude","event":"UserPromptSubmit","sessionId":"09ad8eec","cwd":"/Users/you/work/api-gateway"}
```

Твої промпти, відповіді Claude, аргументи тулів, вміст файлів і транскрипти нікуди
не копіюються й не надсилаються. `backfill` читає локальні транскрипти, щоб дістати
таймстампи, ролі та робочу теку; структуру повідомлення він перевіряє лише настільки,
щоб відрізнити справжній промпт від tool-result, і не зберігає його вміст.

Акаунтів немає. Телеметрії немає. `serve` слухає тільки `127.0.0.1` — ззовні твоєї
машини нічого не видно. На macOS і Linux два `.jsonl` доступні лише власнику.
Видали їх і всі експортовані HTML snapshots, щоб прибрати дані.

## Команди

| Команда | Що робить |
| --- | --- |
| `node hours.mjs backfill` | Підняти історію з минулих транскриптів. `report` і `serve` роблять це самі, якщо файлу 15+ хвилин; руками — тільки якщо хочеш подивитись. Подвоїти не може. |
| `node hours.mjs install` | Read-only перевірити settings і надрукувати лише відсутні хуки; файл не перезаписується. |
| `node hours.mjs report` | Сьогодні. |
| `node hours.mjs report 2026-08-03` | Конкретний день. |
| `node hours.mjs report --days 7` | Останні 7 днів. |
| `node hours.mjs report --json` | Для власних скриптів. `wallMinutes` — об'єднаний agent-active wall-clock. |
| `node hours.mjs report --html` | Паперовий таймшит: тимчасовий файл, що відкривається в браузері. Саме він — для скріншотів. |
| `node hours.mjs statusline` | Один рядок для статус-бара Claude Code — див. нижче. |
| `node hours.mjs serve` | Таймшит на `http://127.0.0.1:4747` — закладка в браузері, рефреш дає свіжі цифри, період перемикається лінками на сторінці. Тільки loopback. |

Змінні оточення: `AGENT_HOURS_FILE` переносить лог, `AGENT_HOURS_DAY_START` рухає
межу доби (типово `5`, тобто сесія о 02:00 йде в учорашній день),
`AGENT_HOURS_DEBUG=1` змушує хук скаржитися замість мовчазного падіння.

## Години в статус-барі

Сьогоднішній agent-active час — постійно на очах, унизу Claude Code:

```
⏱ 2:41 today
```

Додай у `~/.claude/settings.json` — але тільки якщо `statusLine` у тебе ще не
зайнятий: інструменти на кшталт `ccusage` використовують той самий слот, а він один:

```json
"statusLine": { "type": "command", "command": "node \"<абсолютний шлях>/hours.mjs\" statusline" }
```

`node hours.mjs install` надрукує блок уже з твоїм реальним шляхом.

## Або просто спитай

Ти й так цілий день в агенті — то хай він і буде інтерфейсом. Напиши Claude Code
«покажи мої agent-hours за тиждень по проєктах» — він сам запустить звіт і
розкаже цифри. Без скілів, без налаштувань, вчити нічого не треба.

## Два числа

**agent active** — об'єднаний wall-clock, коли працював хоча б один turn Claude Code.
Паралельні сесії рахуються один раз. У JSON поле лишається `wallMinutes` для
зворотної сумісності.

**turn time** — усі turn'и в сумі, з накладеннями. Звіт показує співвідношення
(`×1.23`) — це скільки «тебе» фактично працювало одночасно.

Жодне з них не рахує паузу між відповіддю агента і твоїм наступним промптом. Читання,
думання і ручні правки тут невидимі; водночас агент може працювати, коли тебе немає.
Це активність агента, а не робочий час людини чи автоматична сума для рахунку. Тиша
понад 30 хвилин усередині turn'а вирізається, перерваний turn рахується до останньої
активності, API-помилка закривається через `StopFailure`, а транскрипти субагентів
пропускаються — батьківська сесія вже їх покриває.

## Наскільки це точно?

Два різні питання — дві різні відповіді.

Значення за замовчуванням підібрані після локального аудиту 262 реальних
транскриптів (~118 МБ). Це практичний кейс, а не універсальна гарантія точності:
навантаження й формати транскриптів відрізняються. Джерела похибки:

| Джерело | Знак | Розмір |
| --- | --- | --- |
| Таймстампи хуків / транскриптів | — | секундна точність; зазвичай несуттєво |
| Тиша понад 30 хв | занижує | вирізається як idle або сон, але справді довгий тихий tool call теж може зникнути |
| Live-дані до оновлення транскрипта | завищує | `report` і `serve` уточнюють застарілі події кожні 15 хв |
| Esc-переривання | — | backfill завершує на останній активності, включно з tool-result або interrupt marker |
| API-помилка | — | `StopFailure` закриває turn у момент помилки |
| Вбитий термінал без SessionEnd | завищує | cap 4 години; чистий вихід закривається через SessionEnd |
| Округлення | — | підсумки округлюються до найближчої хвилини |

**Людський час свідомо не вимірюється.** Він може бути більшим через невидиме читання
і ручну роботу або меншим, коли агент працює без нагляду. Для рахунків використовуй
окремий людський таймер чи білінгову систему.

## Чому не щось інше

Трекери токенів і вартості — `ccusage`, `Claude-Code-Usage-Monitor` та інші —
відповідають на інше питання і відповідають добре. Для витрат бери їх.

З тих, що міряють час: `claude-code-wakatime` вимагає акаунт WakaTime і відправляє
твою активність на сервер. `claude_timings_wrapper` розділяє idle і typing значно
точніше, ніж це, але платить за точність PTY-обгорткою і C-тулчейном для збірки
`node-pty`. Тут ця точність обміняна на один файл, який читається за п'ять хвилин.

## Рішення

Кожне неочевидне правило — чому turn закінчується саме там, чому покинута сесія
обрізається на чотирьох годинах, чому доба починається о 05:00 — записане з
обґрунтуванням у [DECISIONS.md](../DECISIONS.md).
